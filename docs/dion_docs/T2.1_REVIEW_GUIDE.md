## 1. What T2.1 built, in five lines

1. One ROS 2 request/reply service, `/segmentation/segment`, owns the only SAM 3. A caller sends
   one rgb8 image and a prompt, optionally depth and camera info. The reply lists every detection.
2. The service keeps no state between calls and knows nothing about the arm, glasses or base.
3. The **grasp client** turns wrist camera frames into service calls and is the only live publisher
   of `/camera/sam/mask`, `/object_centroid_2d` and `/object_centroid`. Same messages as before, so
   AnyGrasp and the state machine did not change.
4. The **aria client** turns a spoken word into a `Target` on `/grasp/target`, which tells the grasp
   client what to look for.
5. The service is started once, on its own, and refuses to start a second time. Launchers start
   only their client.

```
 wrist camera ──colour+depth+info──► grasp client ──Segment request──► segmentation service
                                        ▲      │  ◄──── every detection ──  (owns SAM 3)
 /aria/audio/prompt ─► aria client ─────┘      │
                      (/grasp/target)          ├─► /camera/sam/mask      ─► AnyGrasp, grasp_viz
                                               ├─► /object_centroid_2d   ─► grasp state machine
                                               └─► /object_centroid      ─► grasp_viz
```

## 4. Run it yourself

**On the Mac**, the logic only:

```bash
uv run --no-project --with numpy python -m unittest discover -s shared_services/segmentation -p "test_segmentation_logic.py"
./bench/run.sh quick
```

**On the lab box** (`ssh -o HostKeyAlias=10.91.242.76 rcp2026@100.98.10.50`, then
`cd ~/rcp-Gappler`). Check the GPU and other users first (`nvidia-smi`, `pgrep -af "bench/run.sh|Runner.Worker"`).
Use a normal login shell: AnyGrasp's licence check needs `/sbin` on `PATH`.

```bash
git fetch && git checkout t2.1-sam3-service && git pull      # once the branch is pushed
./build.sh
source global_env.sh
python -m unittest discover -s shared_services/segmentation -p "test_*.py"          # 36
python -m unittest discover -s grasp/grasp_segmentation_client -p "test_*.py"        # 16
python -m unittest discover -s aria/aria_app/services/aria_segmentation_client -p "test_*.py"   # 5
./bench/segmentation_service.sh     # real SAM 3, ~1 min
./bench/anygrasp_replay.sh          # service + client + AnyGrasp on the recording, ~3 min
```

What I got on 2026-10-08 is in `docs/bench-runs/2026-10-08-labbox-t2.1-step*.txt`. Short version:
box found at 0.363 m, about 250 ms a call. 117 masks in 60 s on the replay, against 119 in 61 s
for the old node. A second service copy exits in 0.3 s.

## 5. Choices I made without asking you

These follow from your decisions but the detail was mine. Each one is worth a second look.

| Choice | Where | Why | The other option |
|---|---|---|---|
| `/manipulation/goal_pose` is not implemented at all | grasp client docstring | You said off for now. A switch that is always off is dead code | Build it behind a config flag now |
| A request can raise `min_score` but not lower it below 0.5 | `load_sam3` comment | SAM 3 drops results below the threshold it was built with. Building it at 0 would return every candidate mask on every call | Build SAM 3 at a lower floor (e.g. 0.3) and filter per request |
| Depth units come from the image encoding: `16UC1` = mm, `32FC1` = m | `segmentation_logic.py` | The service serves every camera, so it cannot read one camera's `depth_scale_m` | Send the scale in the request |
| rgb8 only, bgr8 refused | `read_request` | Your call. The RealSense sends rgb8 (confirmed on the recording) | |
| The grasp client is event-driven, no timer | `send_if_ready`, `on_reply` | Always the newest frame, as fast as the service answers | A fixed-rate timer |
| Ties go to the larger mask | `pick_detection` | Matches the page | |
| The grasp client lower-cases the prompt, as does the aria client | both clients | The old pipeline did the same | Leave case alone |
| No centroid when there is no valid depth, but the mask is still published | grasp client `publish` | Same as the old node | Publish nothing |
| The guard waits up to 3 s for discovery | `another_server_running` | Long enough on one machine. Longer delays start-up | |
| `as_numpy` copied from `memory_graph/sam3_adapter.py`, not imported | `segmentation_logic.py` | Keeps the shared service independent of Zongzhe's package | Import it |
| `quickstart full` now includes segmentation | `quickstart_terminals.sh` | It used `nomask` because the old pipeline published masks. It no longer does | Keep `nomask` |
| Quickstart GPU check ignores `gnome-remote-desktop` | `quickstart_terminals.sh` | It always holds 120 MiB, so `aria` and `full` refused every time | Leave it |
| `shared_services` is not in the nav build | `build.sh` | It would be a second copy of the package in a second overlay | Add it now |
