Design agreed with Dion, 2026-10-20 (build in a later session)
1. Embedding: CLIP, reusing memory_graph.clip_encoder.OpenClipEncoder (+ image_feature.l2_normalise).
   The aria app's PYTHONPATH lacks the repo root (the box test added it): fix in the build.
   GPU memory about 0.3 to 0.6 GB [inferred], measure on the box.
2. Crop: the existing _crop_to_mask (box + 20 px), no greying (context helped, 25 vs 20).
3. Rule, in _find_matching_ros_mask:
   a. cosine of every glasses mask vs every wrist mask;
   b. drop pairs below tau (start 0.56, from test 1);
   c. keep pairs within delta of the best (start 0.01);
   d. among those, gaze picks the glasses mask (existing _find_closest_mask);
   e. one wrist mask left: pick it. More than one (identical wrist objects): return None and log
      "wrist tie". Disambiguation by geometry is later (NEXT_STEPS 2.13).
4. _process_aria_frame keeps all glasses masks (today it cuts to the gazed one before storing).
5. SAM 3 cutoff 0.5 -> 0.3 (T2.9 found the same for the glasses box).
6. LightGlue: stop calling it, leave FeatureMatcher in place (may come back). Keypoint outputs
   become empty arrays. Log the score matrix each match.
7. Check both camera feeds reach the matcher in RGB before embedding.
8. Later, not now: SAM 3 (b) for descriptive prompts.
