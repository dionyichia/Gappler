Bug found and fixed in this run
  detect(batched=False) ran out of 16 GB at 163 phrases. The T6.3c refactor collected every
  one-phrase result before converting, and each holds SAM 3's whole state with the image
  features. Fixed in memory_graph/sam3_adapter.py: convert each result before the next call,
  as the code before T6.3c did. The 163-phrase row above is after the fix (5.4 GiB).
