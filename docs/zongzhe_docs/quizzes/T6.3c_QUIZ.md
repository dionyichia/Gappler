### Code issues found in round 1 (none changed)

1. **The batched path runs in float32 if it is called from another thread** `[inferred]`. The
   wrappers turn on bfloat16 autocast with `torch.autocast(...).__enter__()` in the thread that
   builds them (`shared_services/segmentation/segmentation_service.py:125`,
   `aria/aria_app/services/object_recognition/sam3_model.py:62`). Autocast is per thread. If
   `BatchedSam3` is called from a different thread, it runs in float32: slower, and slightly
   different numbers from the one-phrase path. The same is true of the wrappers themselves.
2. **Full-size masks for every kept detection** `[inferred]`. `split_outputs` resizes each kept
   mask to the whole image, as the processor does (`sam3_batched.py:59`). With a lower threshold
   (T6.3c item 3) and many phrases, that is many full-size float masks at once on the GPU. Watch
   the memory in the lab box timing run.
