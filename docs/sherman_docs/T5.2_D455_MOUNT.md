# T5.2: D455 Mobile-Base Mount

**Shared task:** [`../PROJECT_PLAN.md`](../PROJECT_PLAN.md), T5.2.
**Record role:** Sherman-owned design evidence. The shared project plan remains authoritative for task
status.

## Objective

Design a forward-facing, rigid mount for an **Intel RealSense D455** on the Hexman Robotics
ECHO-PLUS mobile base. The shared task requires it to be clear of the arm's swept volume and not view
the robot's own body.

> **Supersession 2026-09-24 (v2):** the v1 mount below is revised by a plate change only —
> same mount, new plate stack putting the camera higher per Dion (reason below). v1 constraints
> and dimensions below are archival except where carried over. Fabrication prerequisites
> (§Still required) transfer to the revised stack.

## Reported mechanical constraints

- `[reported]` The planned mount uses `20 x 20 mm` aluminum extrusion.
- `[reported]` The required extrusion length is `190 mm`.
- `[manual]` The ECHO-PLUS chassis is `460 x 380 x 140 mm`; see
  [`T0.9_BASE_FOOTPRINT.md`](T0.9_BASE_FOOTPRINT.md) for the manufacturer source and chassis envelope.

## Reported completed design

- `[reported]` Mount CAD and dimensions are complete as of 2026-09-16.

## v2 plate revision (2026-09-24, current design)

- `[reported]` Same mount, revised plate stack (Sherman CAD, 2026-09-24, unbuilt, no lab
  access): 3 mm middle plate, **5 mm top platform (current)**. The plate change puts the
  camera higher.
- `[reported]` Requirement (Dion via Sherman, 2026-09-24): the camera sits higher so it
  can see higher for navigation.
- `[reported]` Mounting positions carry over from v1 verified geometry (Dion via Sherman).
- Socket (hole) center = design origin; platform front-top edge at (−13.05, 0, +29.50) mm
  hole-relative, y = 0 centered. Full TF determination (package facts, open chain,
  October taping list) lives in [`T5.4_D455_TF.md`](T5.4_D455_TF.md).
- Still owed before fabrication: fastener spec/positions confirmed against v2 CAD;
  "higher" acceptance = camera sees higher for navigation (verify at T5.3 fit).
