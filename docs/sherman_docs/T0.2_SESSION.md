## What was done

Connected workstation, RM65 arm, and MID-360 LiDAR through an Ethernet switch. Verified
both peripherals are reachable simultaneously from their required host addresses. Made the
address configuration persistent in NetworkManager.

## Switch wiring

| Switch port | Connected to |
|---|---|
| 1 | Lab workstation `enp2s0` |
| 2 | MID-360 LiDAR (Ethernet branch of 3-way harness) |
| 3 | RM65 arm control box |

The MID-360 harness splits into three branches: power, Ethernet, and auxiliary. Only the
Ethernet branch was connected to the switch.

## Persistent NetworkManager profile

Saved profile name: `Wired connection 1`

```text
192.168.1.100/24  (original, kept)
192.168.1.10/24   (arm host address)
192.168.1.5/24    (LiDAR host address)
```

Applied with:

```bash
sudo nmcli connection modify "Wired connection 1" +ipv4.addresses 192.168.1.10/24
sudo nmcli connection modify "Wired connection 1" +ipv4.addresses 192.168.1.5/24
```

Verified by cycling the connection:

```bash
sudo nmcli connection down "Wired connection 1"
sudo nmcli connection up "Wired connection 1"
```

All three addresses survived the reconnect.

## Evidence

### Before cabling

```text
enp2s0: NO-CARRIER
Arm .18: unreachable
LiDAR .3: unreachable
```

### After cabling, before host addresses added

```text
enp2s0: LOWER_UP (active link)
inet 192.168.1.100/24
Arm .18: ping OK (from .100)
LiDAR .3: ping OK (from .100)
```

### After host addresses added

```text
inet 192.168.1.100/24
inet 192.168.1.10/24
inet 192.168.1.5/24
```

### Source-addressed pings (final proof)

```bash
ping -I 192.168.1.10 -c 3 192.168.1.18   # arm
ping -I 192.168.1.5  -c 3 192.168.1.3    # LiDAR
```

```text
RM65 .18 from .10: 3/3 replies, 0% loss
MID-360 .3 from .5: 3/3 replies, 0% loss
```

### After connection cycle (persistence proof)

```bash
sudo nmcli connection down "Wired connection 1"
sudo nmcli connection up "Wired connection 1"
ip -4 addr show enp2s0
ping -I 192.168.1.10 -c 3 192.168.1.18
ping -I 192.168.1.5  -c 3 192.168.1.3
```

```text
All three addresses present after reconnect
Both devices ping from required host addresses
```

## What this proves

The arm and LiDAR can coexist on one wired network through a switch. The workstation holds
all three required addresses and they survive a NetworkManager reconnect. No ROS nodes,
arm commands, or base commands were launched.
