### 6.4 The terminal-message allowance (read this before interpreting a coverage row)

`rosbag2_player` can exit at EOF with its final sample unacknowledged. The allowance permits exactly
one **recorded** loss, and only when **all** of these hold:

1. the LiDAR stream is complete (`missing = 0`, `unexpected = 0`);
2. exactly one other input topic has a gap, and it is exactly **one** message;
3. that stamp is the topic's own last expected stamp;
4. it is **strictly later** than the last observed LiDAR callback;
5. every other topic is exact, after the unchanged IMU prestart allowance (21 messages on both bags);
6. no duplicates anywhere.

When it fires, `result.json` gains `terminal_message_lost = {topic, stamp,
seconds_after_last_lidar}` and `input_lidar_topic`; the coverage row still reports `missing = 1`.
Anything else fails exactly as before. The justification is physical: on the public bag the terminal
camera message postdates the last LiDAR callback by **0.1919 s**, and VIO runs per scan, so no frame
can consume it. Do not extend this to any earlier gap, ever.

## 7. How to audit a run (exact recipe)

```bash
ssh -o BatchMode=yes -o ConnectTimeout=10 -J nvidia@100.118.250.28 rcp2026@192.168.1.100 'L=~/rcp-Gappler/log/t59-fastlivo/replays; D=$L/$(ls -1t $L | head -1); echo "RUN $D"; cat "$D/host-runner.exit-code"; python3 -B - <<PY
import json, re, statistics
from pathlib import Path
d = Path("$D"); r = json.loads((d/"evidence/result.json").read_text())
print("verdict", r["verdict"], "image", r["image_id"][:19], "elapsed", round(r["elapsed_wall_seconds"],1))
print("errors", r["errors"]); print("drain", r["callback_drain"])
print("terminal_message_lost", r.get("terminal_message_lost"))
print("require_visual", r["require_visual"], "visual", r["positive_visual_retrievals"], "eof", r["eof"])
print("streams", {k:(v["count"], v["invalid"]) for k,v in r["streams"].items()})
for t,row in r["input_callbacks"].items():
    print(" in", t, {k:row.get(k) for k in ("expected","observed","missing","unexpected","last_callback_stamp","expected_last_stamp")},
          "pre", row.get("prestart_allowance"), row.get("prestart_drops"))
print("procs", {k:(v["returncode"], v["cleanup_requested"]) for k,v in r["processes"].items()})
print("monitor", {k:v for k,v in r["monitor"].items() if k != "cloud_first_bad"})
print("harness", {k:v[:8] for k,v in r["sha256"].items()})
t = (d/"evidence/mapper.stdout.log").read_text(errors="replace")
rows = [{k:v for k,v in (p.split("=") for p in m.group(0).split()[1:])} for m in re.finditer(r"\[T35_DIAG_CLOUD\][^\n]*", t)]
ret  = [{k:v for k,v in (p.split("=") for p in m.group(0).split()[1:])} for m in re.finditer(r"\[T35_DIAG_RETRIEVE\][^\n]*", t)]
def st(f, rs):
    v = [int(x[f]) for x in rs if f in x]
    return (len(v), statistics.median(v), min(v), max(v)) if v else None
print("rows", len(ret), len(rows), "source", st("source_points", rows), "coloured", st("coloured_points", rows),
      "key_hits", st("key_hits", ret), "shadow", st("shadow_key_hits", ret))
print("empty_coloured", sum(1 for x in rows if int(x["coloured_points"]) == 0))
print("banner", [l for l in t.splitlines() if "BLIND_SQR" in l][:2])
PY'
```

## 8. Pass / fail interpretation

- **PASS** requires: `errors == []`, `eof == true`, every stream present in `expected_outputs` with
  `invalid == 0`, count ≥ 10 and span ≥ 5 s, and (only when `require_visual`) ≥ 2 positive visual
  retrievals; all under the 600 s budget.
- Coverage must be exact per topic, except the bounded terminal allowance in §6.4.
- IMU prestart drops are legitimate only inside the 21-message allowance and only as a strict
  startup prefix; anything else is a gap.
- A run that passes while a *new* failure mode appears still needs that mode written down. Passing
  is not permission to ignore anomalies.
- `INCONCLUSIVE` is not a pass. A paused diagnostic run (`--diagnostic`) is never acceptance.

## 12. Gotchas that have bitten already

- `zsh` treats a bare `===` as a glob error. Quote echo separators.
- `git diff --check` rejects a file ending in a blank line; write exactly one trailing newline.
- A "ran" message with no new run directory means the Enter never landed (see §4.4).
- `cp -a "$SRC/." "$NEW/"` copies the *contents*; put `replay/` in the destination path explicitly.
- The replay wrapper streams the bag into the container with `tar`; the 2.2 GB stationary02 bag adds
  noticeable startup time. Budget for it.
- Public-bag playback is 66.68 s at rate 0.25 → ~267 s; stationary02 is 74.65 s → ~299 s. The
  wrapper refuses rates that would break the 600 s custody window.
- `run_replay.sh` refuses if `software-build.lock` is held, if the custody hold file exists, or if a
  conflicting build/replay is running. Never remove someone else's lock.
- `[T35_DIAG_CLOUD]` / `[T35_DIAG_RETRIEVE]` rows only exist with `img_en=1`; do not compare A and B
  point counts through them.
- The mapper's camera subscription is depth 200,000 RELIABLE; subscriber-side loss is implausible, so
  do not chase it. `/rgb_img` is advertised with depth 1 BEST_EFFORT, which is why its monitor count
  wobbles (606 / 441 / 430 / 389) and why the count is not a gate.
