Expected in source.patch: two comment lines, then exactly one behaviour line —

p_pre->blind_sqr = p_pre->blind * p_pre->blind;

— then the tagged print. Expected from the binary strings: [T35_BLIND_SQR] blind=. The patch changes no other source text: removing every /* T35_BLIND_SQR */ line restores the pinned LIVMapper.cpp byte-for-byte, and the repo's test asserts that against the pinned source.

8. What this measurement does not prove

Nothing about map quality, pose drift or moving-map behaviour: a stationary replay with fewer points in the map is a gate measurement, not an accuracy result. It does not decide whether the patched image becomes the consumer of record — that is a separate reviewed decision, and if it is adopted the pinned image stays the control, the frozen pair stays byte-unchanged, and a pair adopted for a later run still owes the corrected extrin_calib.extrinsic_T with the in-place spin test.
