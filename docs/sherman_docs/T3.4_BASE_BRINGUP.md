## Isolated limiter result

`[observed, direct]` Installed `nav2_velocity_smoother` was tested on an initially empty domain
127 with `ROS_LOCALHOST_ONLY=1`. Its input/output were `/t34_probe/keyboard_input` and
`/t34_probe/output`, never the real base's `/cmd_vel`. Lifecycle configure/activate succeeded.
Oversized forward/turn and reverse/turn inputs were each supplied for eight 0.1-second intervals.

- Smoothing frequency 20 Hz, open-loop feedback, limits +/-0.05 m/s and +/-0.15 rad/s.
- Acceleration limits 0.1 m/s² and 0.3 rad/s²; deceleration magnitudes 0.2 and 0.6 respectively.
- Input timeout 0.25 seconds; zero output observed 0.500 seconds after the final input in both
  directions, including ramp-down. All sampled outputs stayed within the configured limits.
- Probe processes were stopped and the private domain was checked empty afterward.

This was an exploratory probe, **not** a maintained bench check or a deployed control path.
It does not establish braking, behavior after process failure, or stopping after a network loss.
