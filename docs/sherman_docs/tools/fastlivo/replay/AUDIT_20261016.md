## Pinned-source findings and remaining hypotheses

- `src/LIVMapper.cpp:714–734`: ROS validity checked at loop entry, followed by
  `spin_some`, synchronization, IMU processing and state estimation.
- `src/LIVMapper.cpp:1557–1575`: every odometry publication constructs another TF
  broadcaster. A signal during the iteration can plausibly invalidate ROS before
  this publisher construction. A throwing stack is still required to confirm.
- `include/utils/utils.h:17–20`: `stamp2Sec` uses `rclcpp::Time(stamp).seconds()`.
- `src/LIVMapper.cpp:1398–1410`: cloud output uses current ROS clock time; reaching
  the recording's final clock does not prove sensor processing reached its end.
- Original segfault cause remains open. Mixed instrumentation is not itself a
  diagnosis. Neither clean no-data shutdown nor an absent ASan report proves a
  particular heap bug, a necessary data precondition, or a threading race.
