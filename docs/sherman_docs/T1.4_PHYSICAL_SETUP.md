**Sessions 2026-09-22, Sherman (Mac + lab box) + Dion (owner, aware).**

**Shared task:** task `T1.4` in [`../task-tree.html`](../task-tree.html).
**Record role:** Sherman-owned planning record. The task tree remains authoritative for task status.

## Objective and scope

T1.4 is the physical safety setup at the robot: clear working volume, stop button within reach,
mount and cable check. T1.4 gates T1.6 (first power, no motion commanded) — not T1.7 (first
commanded motion). Motion safety stays downstream with T1.3 (validated home pose), T1.6 (joint
feedback), and T1.7 (supervised move).

Because no physical table/cell exists yet, this plan splits T1.4 into a robot-side half that can
be done now and a cell half that stays blocked.

- **T1.4-now:** robot-side safety setup and as-built measurements for power-on readiness. No arm
  motion, no motion commanded.
- **T1.4-cell (blocked):** table geometry, grasp zone, wrist-camera view of objects, approach
  clearance. Required before any grasp-volume claim or real motion — not before power-on.

**Lean rule:** T1.4 DONE means safe for power-on with no motion, plus documented residuals. Sweep
bounds, wall-vs-volume proof, TF closure to the millimetre, Nav2 footprint closure, ROS/power-on
procedure, camera health, and D455 mount work belong to T1.3/T1.5/T1.6/T1.7/T0.9/T5.x — not to
T1.4 DONE.

## Ground rules

- Arm stays unpowered. Joints stay untouched. The as-found posture is arm straight up.
- Forcing braked joints can damage motors, gearboxes, brakes, or encoders. The vendor driver
  reports joint-brake state (`arm/vendor/rm_driver/include/rm_driver/rm_interface.h:449`), and its
  error table names "joint brake is not opened".
- Camera work is camera-only (USB power, no arm motion), with shared-hardware checks first.
- No table/cell means no grasp-view claim and no final home-pose claim.

## Measurement conventions

- Meters unless stated. Three readings per row; retain the largest safety-relevant value.
- Photo ID per row. Front, side, overhead, serial plates, every measured edge.
- `[manual]` manufacturer or datasheet value. `[reported]` a person-supplied value with who/when.
- `[code]` read from source at the cited line. `[manual]` physical readings get recorded with method.

## B. Static envelope (x-y containment + heights)

| ID | Quantity, unit | Exact procedure |
|---|---|---|
| B1 | Static x-y containment | At each of the 4 chassis edges: sight straight down along the edge plane and confirm no fixed hardware (extrusion housing, computer, PSU, LiDAR body, mast base, camera bodies, cable bodies and plugs) crosses it. Where clearance is under ~2 cm, tape the gap. Record pass/fail per edge. Structure footprint (old C2) is checked here, not twice |
| B2 | Connector overhang, m | In plan view, find the plug/cable end protruding furthest past its nearest edge. Tape the horizontal distance from the edge plane to the tip. 3 readings, reseating the tape each time; retain largest. Record 0 plus the part name if nothing protrudes |
| B3 | Static max radius, m (supporting evidence, not a DONE gate) | Mark the floor center: halve measured chassis L/W, transfer the midpoint to the floor with a plumb line, tape cross. Walk around; find the furthest fixed hardware point in plan view (exclude future arm sweep; include the as-found arm only as it sits). Drop a plumb line or ruler from that point to the floor; tape horizontal center-mark to floor-projection. 3 readings; retain largest; record which part set it. Duplicates T0.9 metrology; keep for the record only |
| B4 | Overall height as-found, m | Tape vertical from floor to the highest fixed point (as-found arm tip or mast top, whichever is higher; record which). Hold the tape plumb. 3 readings; retain largest |

## C. Extrusion housing + arm mount

| ID | Quantity | Exact procedure |
|---|---|---|
| C1 | Extrusion profile, mm (optional) | Caliper or tape across an exposed extrusion end; record both sides in mm. Stock-size confirmation only |
| C3 | Structure height, m | Tape vertical from the chassis top plate to the top face of the arm-mount plate. 3 readings; retain largest |
| C4 | Arm flange forward offset, m | Establish the forward axis: mark the width midpoint at the chassis front and rear, run a string line between them. Record and flag disagreement; millimetre closure belongs to T5.4 |
| C5 | Arm flange height, m | Tape vertical from the chassis top plate to the arm-flange mounting face. 3 readings; compare model `0.48 m` ± 0.02. Record and flag disagreement; millimetre closure belongs to T5.4 |

Record which way the arm's joint-1 cable port / base seam faces and whether the arm X-axis runs with robot-forward (model: yaw π, mounted rotated 180°). | C7 | Housing contents | List every item inside/under the extrusion (PSU model, computer model, left/right/front/rear placement), ventilation openings present Y/N. Visual only, no opening housings |
| C8 | Fasteners/stability | Count visible bolts holding extrusion-to-chassis and plate-to-extrusion; record sizes (M5/M6/etc.) and any missing/loose ones. Press firmly on the extrusion only (never the arm); record solid vs play and where |
| C9 | Cable entry/exit + slack, m | Per cable: connector A → connector B, route (clipped/free), slack length (tape the free loop), strain relief Y/N, every edge or corner it crosses (snag points) |

## How these feed T1.3

- Containment + max radius support (not prove) later safety-wall checks against the real cleared volume; the wall-vs-volume proof belongs to the T1.3 candidate / T1.7 preconditions.
- Flange offsets/yaw test the TF (transform tree) mount assumptions behind every FK, approach, and
  wall comparison.
- Heights + as-found posture set vertical bounds and the reference state.
- Camera identity + FOV reference predict whether a candidate home can see a future grasp zone.
- Joint limits + the joint4 failure history supply the margin math for screening candidates.
- Photos + retained-largest values make the derivation auditable.
